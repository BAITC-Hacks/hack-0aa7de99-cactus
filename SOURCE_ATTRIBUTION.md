# Source attribution and import scope

The `protokol/` application code was imported from the private repository [`adiletexe/hackalem-protokol`](https://github.com/adiletexe/hackalem-protokol), source commit `409ecee9322349e7b37148b5420c5fb43b383ddb` (2026-09-23), authored by `adiletexe <ausarbekovadilet@gmail.com>`. That source commit also credits Claude Opus 5 as a co-author. The official repository's prior history and authors remain intact.

This is a selective code import because the source commit also contains generated meeting transcripts and protocols. Imported: the root Python application modules, `ui.html`, and `requirements.txt`, placed under `protokol/`. Adapted: the web app's local path handling, empty participant form, current date default, and setup documentation.

Excluded: all `demo/` files, `gold.json`, `roster*.json`, the source README's meeting excerpts, and example-dependent benchmarks. No source commit or Git object was merged into the official history. Model weights, meeting audio, transcripts, generated protocols, and voiceprints are not part of this import.
